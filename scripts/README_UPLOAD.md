# رفع نموذج YOLOv8 إلى Roboflow

يرفع هذا السكربت أوزان YOLOv8 إلى مساحة عمل Roboflow، ويربطها بمشروع كشف أجسام. إذا لم يكن المشروع موجوداً، يحاول إنشاء مشروع خاص باسم `amal-x-ray-center`. مسار النموذج الافتراضي هو ملف `best.pt` الموجود في هذا المستودع، ويمكن تغييره من `MODEL_PATH`.

## المتطلبات

من جذر المشروع، ثبّت الاعتماديات في بيئتك الافتراضية:

```powershell
python -m pip install -r requirements.txt
```

أنشئ السكربت ملف `.env` في جذر المشروع. املأ `ROBOFLOW_API_KEY`، وإذا لم تكن مساحة العمل الافتراضية صحيحة فاملأ `ROBOFLOW_WORKSPACE` أيضاً.

## الحصول على مفتاح Roboflow

سجّل الدخول إلى Roboflow، ثم افتح [إعدادات API](https://app.roboflow.com/settings) وانسخ مفتاح API الخاص بحسابك. لا تشارك المفتاح ولا تضعه في ملفات تُرفع إلى Git.

## مثال إعداد الرفع في `.env`

```dotenv
ROBOFLOW_API_KEY=rf_ضع_مفتاحك_هنا
ROBOFLOW_PROJECT_NAME=amal-x-ray-center
ROBOFLOW_WORKSPACE=اسم_مساحة_العمل
MODEL_PATH=runs/detect/runs/dental_gtx1650-3/weights/best.pt
```

يمكن ترك `ROBOFLOW_WORKSPACE` فارغاً لاستخدام مساحة العمل الافتراضية المرتبطة بالمفتاح. المسارات النسبية في `MODEL_PATH` تُحل نسبةً إلى جذر المستودع، وليس إلى مجلد PowerShell الحالي.

## التشغيل

من جذر المشروع:

```powershell
python scripts/upload_to_roboflow.py
```

يرفع السكربت النموذج باسم `yolov8n-dental-v1`، ثم يطبع رابط المشروع عند تأكيد اكتمال الرفع. إذا كان المشروع جديداً، ينشئه بترخيص خاص ونوع كشف الأجسام.

## إكمال Label Assist

واجهة Roboflow Python SDK تتيح رفع الأوزان وربطها بالمشروع، لكنها لا تفعّل جلسة Label Assist ولا تختار النموذج تلقائياً داخل أداة التعليق. بعد نجاح الرفع:

1. افتح رابط المشروع الذي طبعه السكربت.
2. افتح **Annotate** واختر صورة من مجموعة البيانات.
3. اضغط أداة العصا السحرية **Label Assist**.
4. اختر النموذج `yolov8n-dental-v1` من **Your Models**، ثم أكمل اختيار الفئات.

قد يتطلب إنشاء مشروع خاص خطة Roboflow تسمح بالمشاريع الخاصة. إذا رفض Roboflow الإنشاء، أنشئ مشروع كشف أجسام خاصاً يدوياً ثم أعد تشغيل السكربت.

## ملاحظات الأمان

- ملف `.env` مستثنى من Git عبر `.gitignore`. لا تغيّر ذلك ولا ترفع المفتاح إلى المستودع.
- لا يطبع السكربت قيمة مفتاح API في السجل.
- السكربت يرفع ملف الأوزان ولا يرفع صور المرضى أو بياناتهم.
