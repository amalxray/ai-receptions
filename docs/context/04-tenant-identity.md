# هوية المستأجر — عقد النطاقات (S1/S3)

المصدر القانوني: `../AEO-GEO.md` (§9 و§9.1). هذا الملف ملخص تنفيذي فقط.

## القاعدة الذهبية

النطاق الفرعي `https://{slug}.dentairec.com` هو الـ**canonical** الوحيد.
كل سطح يعلن شكلًا واحدًا: `canonical` + `og:url` + JSON-LD + sitemap + QR.

## البوابة المزدوجة للتحويل 301

`www.dentairec.com/{slug}` يُحوَّل **فقط إذا**: الـslug موجود في DB **و** النطاق مسجّل في Vercel.
غير ذلك: يعمل المسار 200 كالسابق (لا تحويلة ميتة أبدًا).

## Fallback الموحّد

أي رابط لعيادة غير جاهزة يسقط على `/c/{slug}` (صفحة التوافق، noindex):
QR، بطاقات `/ask`، `booking_url`، روابط اللوحة، JSON-LD الطبيب.
الدالة: `tenantPublicUrl(slug, ready)` في `lib/vercel/tenantLinks.ts`.

## ما تم (P0/P1)

- **P0**: 6 نطاقات مسجّلة في Vercel (`verified=true`) + حالة محفوظة في `settings.tenant`.
- **P1**: طبقة الجاهزية + البوابة المزدوجة + fallback في 8 مُصدِّرين + زر «أعد التجهيز» + sitemap يستبعد غير الجاهز.

## قيود ثابتة

- `/d/{slug}` يبقى path (الطبيب ليس مستأجرًا، وتسمية `dr-*` قد تتصادم).
- `www.{slug}.dentairec.com` مستحيل تقنيًا (شهادة بمستويين) — يعمل عبر HTTP فقط.
- التجهيز best-effort: لا يمنع التسجيل أبدًا، والفشل يُسجَّل ويُعرض مع زر إعادة.
