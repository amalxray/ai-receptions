# 🗺️ خريطة مشروع Dentairec

**الإصدار:** 2.0 | **آخر تحديث:** 2026-11-24 | **الغرض:** وثيقة مرجعية استراتيجية.

## 1. الرؤية
منصة SaaS متكاملة لأتمتة إدارة العيادات (أسنان، أشعة، مختبرات) بالذكاء الاصطناعي، من الاستقبال حتى التحليل الإشعاعي.

## 2. البنية التقنية
- **الواجهة/الخلفية:** Next.js 14 (App Router) + React 18 + TypeScript.
- **قاعدة البيانات:** Supabase (PostgreSQL) مع RLS صارم.
- **الذكاء الاصطناعي:** بنية متعددة المزودين (OpenAI, Anthropic, Gemini, Groq, Ollama) عبر `Provider Registry` مع Failover.
- **الاستضافة:** Vercel (الواجهة)، Render (خدمة استدلال ONNX للأشعة).

## 3. الوحدات الحالية
- **إدارة العيادات:** تسجيل، اشتراكات، فريق، صلاحيات.
- **المواعيد:** تقويم، حجز ذكي، تكامل Google Calendar.
- **الملف الطبي:** ملف مريض ذكي، فواتير، رواتب، إدارة ملفات TUS.
- **الذكاء الاصطناعي:** Ask (دردشة ذكية)، Sales-Bot، Knowledge Base (RAG)، تحليل أشعة (Panorama/CBCT).
- **النمو:** Growth (صفحة إعلانات و Leads ومحتوى عام).

## 5. الوكلاء الرقميون (الطبقة الجديدة)
- **الاستراتيجية:** التوسع في Module الـGrowth الموجود.
- **المكان:** `lib/services/marketing/` + `app/api/agents/marketing/route.ts`.
- **الآلية:** إعادة استخدام `Provider Registry` + `Knowledge Base`.
- **البدء بـ:** Human-in-the-loop (مسودات فقط).

## 6. الأولويات قبل بناء الوكلاء
1. تنظيف المستودع (B146, Kimi_Agent).
2. إصلاح الاعتماديات (react-pdf, tus-js-client).
3. تأمين البيئة (.env.backup).
4. تثبيت CI (lint + test).

## 7. الفريق الرقمي المقترح
- **Marketing Agent:** توليد محتوى تسويقي.
- **Sales/SDR Agent:** استهداف عيادات جديدة.
- **Support Agent:** الرد على استفسارات العملاء.
- **Analyst Agent:** تحليل الأداء واقتراح تحسينات.
